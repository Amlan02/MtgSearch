# Scryfall Price Fetcher

This project is a simple Python application that fetches the prices of Magic: The Gathering cards using the Scryfall API.

## Project Structure

```
scryfall-price-fetcher
├── src
│   ├── main.py          # Entry point of the application
│   └── scryfall_api.py  # Functions to interact with the Scryfall API
├── requirements.txt      # List of dependencies
└── README.md             # Project documentation
```

## Requirements

To run this project, you need to install the required dependencies. You can do this by running:

```
pip install -r requirements.txt
```

## Usage

1. Run the application:

```
python src/main.py
```

2. When prompted, enter the name of the Magic: The Gathering card you want to check the price for.

3. The application will fetch the current price of the card and display it.
